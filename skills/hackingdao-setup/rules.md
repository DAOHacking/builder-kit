# Build rules

How HackingDAO builders and their coding agents work. Short on purpose.

## Code

- Install with `npm ci --ignore-scripts` and commit the lockfile.
- Read the code and report what you found before editing it.
- Change only what the task needs.
- Scratch scripts delete themselves when done.
- Verify before saying it works. Say plainly what was not checked.
- One issue per pull request. Keep pull requests small.

## Writing

- No filler. No hype.
- No em dashes.
- Say it once.

## Design

- No purple, no gradients, no coloured side bars.
- UI is designed, never placeholder.

## Motion

- No screen shake, zoom punches, motion blur or chromatic aberration.
