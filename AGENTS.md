# Agent instructions

This is the HackingDAO builder kit.

When a builder asks you to set them up for HackingDAO, or to claim an issue, start, sync, ship or clean up after a merge, read and follow [skills/hackingdao-setup/SKILL.md](skills/hackingdao-setup/SKILL.md). Its rules for code, writing, design and motion are in [skills/hackingdao-setup/rules.md](skills/hackingdao-setup/rules.md).

Use [skills/no-slop/SKILL.md](skills/no-slop/SKILL.md) on anything you write for the builder. When they ask for posts about a build session, use [skills/sessionclips/SKILL.md](skills/sessionclips/SKILL.md).
